# my-react-app-first

🚀 This is my first React app created.  
The project is focused on learning core React concepts, component structure, and modern front-end tooling using npm and VS Code.

---

## React + Vite

This project uses Vite to provide a fast development environment with HMR and ESLint rules.

Two official plugins are available:
- @vitejs/plugin-react (uses Oxc)
- @vitejs/plugin-react-swc (uses SWC)

## React Compiler
The React Compiler is enabled in this template.
